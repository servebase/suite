幫我分析一下 @plotdb/servebase 這個專案. 簡單說明一下
這是一個完整網路服務的基板, 一般使用模式是 fork 他後 rebase 做開發.
源碼部份, 後端在 backend/, 前端在 frontend/base (這是範例, fork 版一般會在 frontend/web)
設定在 config, 內部元件會在 modules/
前端外部元件會透過一個叫 fedep 的專案複製到 frontend/base/static/assets/lib 下
fedep 我整理一份源碼在 context/fedep 給你參考
前端源碼透過 @plotdb/srcbuild 編譯, 我將 srcbuild 源碼整理一份在 context/srcbuild 給你參考
基本文件在 doc

我想請你分析一下這個專案的結構, 然後整理他的設計概念, 把資訊整理到 context/project 目錄下.
專案架構較複雜, 你可以視情況用多個檔案或子目錄來管理資訊, 但我希望資訊精簡, 不要過多贅詞跟樣式.
要條列項目的話可以用 list, 避免用表格.
連同 fedep 與 @plotdb/srcbuild 一同做個資訊整理.

此外, 請你做一個總摘要檔案, 供未來的你可以讀取快速理解 servebase
並且你的文件架構跟內容要讓未來的你可以知道必要時可以再到哪個文件中了解細節.
目標是讓你對專案有足夠的了解，可以配合我進行協同開發.
